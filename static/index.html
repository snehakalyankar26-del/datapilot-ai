    The Autonomous Agentic Loop

    1. Guard — Sanitise question, block prompt-injection and control characters.
    2. Cache — High-speed LRU+TTL answer cache returns repeated questions in 0.04 ms.
    3. Plan — Google Gemini reads a compact, masked schema and reasons over the required query strategy.
    4. Generate SQL — Generates one read-only query returned as strict, validated JSON.
    5. Validate & Execute — 7 security layers: static AST guard, low-level engine authorizer, BigQuery dry-run guard.
    6. Self-Repair — On syntax or execution error, the error feedback is piped back to Gemini for self-repair (up to 2 retries).
    7. Visualise — Dynamic chart specification (bar/line/pie/scatter) validated against actual result columns.
    8. Explain — Plain-English executive narrative + bullet insights.
    9. Grounding Verification — Every numeric token in the narrative is cross-checked against result rows (100% grounding score guarantee).
